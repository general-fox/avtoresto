# Avtoresto

Адаптивный сайт Avtoresto — партнёра iiko для сегмента HoReCa. Реализация на HTML, CSS и JavaScript, без сторонних пакетов и внешних сервисов для работы интерфейса.

Текущий этап — воспроизведение главной по [макету Figma 2250:971](https://www.figma.com/design/hS1IyDhEb9iZ9iqek7ZBxS/Untitled?node-id=2250-971), начиная с первого экрана. По запросу владельца зелёное оформление отменено: возвращены белый фон, бордовые и розовые поверхности, исходная композиция и тексты. Остальные разделы сохраняют рабочую реализацию в исходной палитре, но их точное соответствие макетам ещё требует дальнейшего согласования.

## Локальный просмотр

Нужен установленный Node.js 20 или новее. В Windows откройте `start-local.cmd` двойным щелчком и перейдите на http://127.0.0.1:4173.

Или из папки проекта:

```sh
npm run build
npm run dev
```

Окно сервера должно оставаться открытым. Для другого порта задайте переменную `PORT`.

## GitHub Pages

Репозиторий: https://github.com/general-fox/avtoresto

Для репозитория включён источник **GitHub Actions**. Workflow `.github/workflows/pages.yml` собирает и публикует папку `dist` при обновлении ветки `main` или при ручном запуске. Подпапка репозитория учитывается автоматически через `base_path` GitHub Pages. Основной сайт может использовать собственный домен без изменения кода.

Workflow основан на [официальной документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## Содержание и поведение

- Главная: две карточки оборудования и обслуживания с исходными текстами, четыре пустых блока из макета и полоса логотипов.
- Двухуровневая шапка с логотипом, адресом из Figma, ссылкой на Telegram и навигацией. Номер телефона заменён на Telegram.
- Оборудование: фильтрация и отдельные карточки трёх комплектов.
- Поддержка: три плана и отдельные страницы подробностей.
- iiko: возможности и подбор конфигурации.
- О компании и контакты.
- Подготовка заявки в модальном окне, просмотр, копирование и редактирование.
- Мобильная навигация, FAQ, увеличение оборудования и переключение логотипов.
- Страница конфиденциальности и 404. Cookie-баннера нет: приложение не устанавливает cookies, не подключает аналитику и не сохраняет настройки в браузере.

## Заявки

Канал обращений: **https://t.me/posadmin_request_bot**. Телефоны из Figma на сайте не используются.

Форма **не отправляет заявку автоматически**. Она формирует текст, посетитель копирует его и отправляет боту в Telegram. Сообщение об успешной доставке не показывается. Введённые данные не сохраняются в localStorage и не передаются на сервер сайта.

Для автоматической доставки потребуется отдельный серверный обработчик с токеном Telegram-бота и адресатом. Токен нельзя добавлять в клиентский JavaScript или публичный репозиторий. В этой версии серверной интеграции нет.

## Данные из дизайна

На сайте используются оригинальные изображения оборудования, графические элементы и логотипы из Figma. Фотографий ресторанов, еды и сгенерированных иллюстраций нет. На главной восстановлены тексты предложений и адрес из макета. Телефоны исключены по указанию владельца. Во внутренних разделах стоимость предлагается рассчитать индивидуально. Коммерческие условия и актуальность сведений следует подтвердить перед основным запуском.

14 исходных ссылок включают страницы, повторные варианты и состояния. Рабочее сопоставление находится в `DESIGN-COVERAGE.md`; оно описывает покрытие сценариев, а не подтверждает точное завершение всех 14 макетов. Сейчас визуальная сверка сосредоточена на главной `2250:971`.

## Где редактировать

- `dist/app.js` — контент, страницы и взаимодействия.
- `dist/styles.css` — базовая вёрстка, компоненты и адаптивность.
- `dist/refinement.css` — актуальная палитра, типографика, оформление страниц и адаптивные уточнения; подключается после базовых стилей.
- `dist/assets` — локальные изображения, шрифты и лицензия шрифта.
- `src/index.html` — шаблон HTML, метаданные и точки подключения.
- `scripts/build.mjs` — генерация статических входных страниц и путей GitHub Pages.
- `server.mjs` — локальный сервер.

После изменений шаблона выполните `npm run build`. Изменения JS и CSS видны после обновления страницы.

## Проверки

```sh
npm run build
npm run check
```

Проверяется наличие 12 страниц и 404, локальных изображений, корректность базового пути, контакт Telegram и отсутствие старого номера в приложении. Дополнительно вручную проверяются меню, фильтры, FAQ, модальное окно, форма и адаптивная вёрстка в браузере.

## Шрифты

Source Sans Pro используется для интерфейса, League Spartan — для логотипа. Файлы `dist/assets/source-sans-pro-*.ttf` и `dist/assets/league-spartan-light.ttf` поставляются вместе с сайтом и загружаются с него, без обращения к Google Fonts. Лицензии сохранены в `dist/assets/source-sans-license.txt` и `dist/assets/league-spartan-license.txt`.
